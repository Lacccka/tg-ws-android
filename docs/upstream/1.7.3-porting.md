# Upstream v1.7.3 porting notes

Upstream v1.7.3 temporarily added active WebSocket keepalive support: outbound
WebSocket PING generation, a bridge keepalive companion task, a configurable
keepalive interval, and keepalive counters/diagnostics.

Android previously ported that behavior, but upstream later reverted active
WebSocket keepalive in v1.8.0 because it caused more operational issues than it
solved. Android now follows the v1.8.x behavior: the active/outbound keepalive
port has been removed from the proxy transport.

## Current Android behavior

- `BridgeSession` runs only the two data-copy directions. It does not start a
  WebSocket keepalive companion thread and does not send periodic outbound PING
  frames.
- `RawWebSocket` no longer exposes a public outbound `sendPing` API.
- `ProxyServerConfig` and persisted `AppConfig` no longer include a
  `wsKeepaliveIntervalSeconds`/`ws_keepalive_interval_seconds` setting. Older
  persisted JSON keys are ignored.
- Proxy stats and diagnostic reports no longer include WebSocket keepalive
  counters or failure reasons.
- Passive inbound WebSocket control-frame handling remains: inbound `OP_PING`
  frames are answered with masked `OP_PONG` frames, and inbound `OP_PONG` frames
  are still ignored.
- Connect and HTTP WebSocket upgrade/handshake timeouts remain bounded.
- Post-handshake WebSocket frame reads do not use a fixed idle timeout; an idle
  bridged WebSocket is not closed solely because no frame arrived after a fixed
  local timeout.

## Historical v1.7.3 items

| Upstream area | v1.7.3 behavior | Android status |
| --- | --- | --- |
| `proxy/bridge.py` | Added `_ws_keepalive(ws, interval)` and ran it beside the two bridge copy tasks. | Previously ported; now removed/reverted for v1.8.x parity. |
| `proxy/raw_websocket.py` | Added public `send_ping(payload=b'')` for masked outbound PING frames. | Previously ported; now removed/reverted for v1.8.x parity. Passive inbound PING -> PONG remains. |
| `proxy/config.py` / CLI | Added `ws_keepalive_interval` / `--ws-keepalive`. | Previously ported; now removed/reverted. Existing persisted Android keys are ignored. |
| Diagnostics/tests | Added keepalive counters, failure diagnostics, and active keepalive tests. | Removed with the active keepalive port. Tests now cover passive PING -> PONG and timeout-boundary behavior. |
